# AGENTS.md

Run `./dev.sh help` to learn how to start, stop, and read the logs of the dev server.

Every page must support both light and dark mode. Pair each color utility with a
`dark:` variant (e.g. `bg-white dark:bg-zinc-950`). Dark mode is class-based: `src/theme.js`
toggles `.dark` on `<html>` from the light/dark/system switch.
